---
title: Keyboard shortcuts
description: Every default shortcut in twig, and how to rebind them.
---

Everything twig does is on a real menu with a real shortcut. These are the defaults:

| Shortcut | Action |
| --- | --- |
| <kbd>⌘T</kbd> / <kbd>⌘W</kbd> | New tab / close tab |
| <kbd>⇧⌘T</kbd> | Reopen closed tab |
| <kbd>⇧⌘W</kbd> | Close window |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> | Jump to tab |
| <kbd>⇧⌘[</kbd> / <kbd>⇧⌘]</kbd> | Previous / next tab |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | Back / forward |
| <kbd>⌘L</kbd> | Focus the address bar |
| <kbd>⌘K</kbd> | Command palette |
| <kbd>⌘E</kbd> | Follow a link by keyboard |
| <kbd>⌘F</kbd> | Find in page |
| <kbd>⌘R</kbd> | Reload |
| <kbd>⌘+</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> | Zoom in / out / reset |
| <kbd>⇧⌘R</kbd> | Reader view |
| <kbd>⌘B</kbd> | Toggle the tab strip |
| <kbd>⌘D</kbd> | Bookmark this page |
| <kbd>⇧⌘O</kbd> / <kbd>⌘Y</kbd> | Bookmarks / history |
| <kbd>⇧⌘N</kbd> | New private window |
| <kbd>⇧⌘S</kbd> | Save current space as a checkpoint |
| <kbd>⇧⌘H</kbd> | Browse checkpoints |
| <kbd>⌥⌘P</kbd> | Package the current space |
| <kbd>⇧⌘P</kbd> | Research package library and import |
| <kbd>⇧⌘F</kbd> | Recall a passage |
| <kbd>⌥⌘S</kbd> | Snooze tab |
| <kbd>⌘,</kbd> | Settings |

## Rebinding

Every one of these can be changed. Open **Settings → Shortcuts**, or ⌘K → *Customize keyboard shortcuts*, pick an action and press the keys you want. You can also set them during the welcome tour.
