Press **⌘K** to open the palette. Start typing and it searches several places at once, grouped so you can see what each row is:

| Group | What's in it |
| --- | --- |
| Go | Open what you typed as an address or a search |
| Open tabs | Tabs in your spaces |
| Bookmarks | Your bookmarks |
| Recent / History | Pages you've visited |
| In pages you've read | Matches inside the text of pages, from [Recall](/docs/recall) |
| Commands | Things twig can do |

Use **↑** and **↓** to move, **↵** to open, and **esc** to close.

## Commands

Commands include New tab, Close tab, Reopen closed tab, New private window, Snooze tab…, Save checkpoint, Show checkpoints, Package current space, Show research packages, Recall a passage, Show what changed, Show bookmarks, Show history, Toggle tab strip, Settings, Customize keyboard shortcuts, Report a bug, and Welcome to twig. Rows show their shortcut where there is one.

This website has a palette too: press ⌘K or Ctrl+K on any page outside the docs to jump to a section, a page or a doc.
