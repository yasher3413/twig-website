## From inside twig

Open **Help → Report a Bug…**, ⌘K → *Report a bug*, or **Settings → Browser**. The form asks:

- **What happened?**
- **What did you expect?** (optional)
- **How can we reach you?** (optional)

You can attach a screenshot: click *Attach a screenshot*, paste one with ⌘V, or drop an image on the form. twig shrinks large images before sending.

twig files the report as a GitHub issue for you and shows its number and a link, so you can follow it.

## What's sent

Only what you write, the screenshot if you add one, and the twig and macOS versions if you leave that box ticked. twig never sends the page you're on or your history.

<Callout type="warn" title="Reports are public">
Reports become public GitHub issues, and screenshots are stored publicly. Leave out anything private.
</Callout>

Reports go through a small relay hosted on Vercel, which turns them into issues. It uses your IP address briefly to limit how often reports can be sent, and Vercel may keep request logs. See the [privacy policy](/legal/privacy).

## On GitHub

You can also [open an issue](https://github.com/yasher3413/twig/issues/new) directly, or browse [existing issues](https://github.com/yasher3413/twig/issues).
